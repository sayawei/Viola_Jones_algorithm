# Viola_Jones_algorithm

This project implements Viola-Jones Object Detection using Haar Cascade Classifier in OpenCV to detect cars in real-time through a webcam.

## About Viola-Jones Algorithm

The Viola-Jones algorithm (proposed in 2001) is a fast and robust object detection method widely used for face detection and vehicle recognition. It is based on:
- **Haar-like Features – Feature extraction using rectangular filters.**
- **Integral Image – Speed optimization for feature calculations.**
- **AdaBoost Classifier – Training weak classifiers into a strong classifier.**
- **Cascade Classifier – A stage-wise approach for efficient object detection.**
